# Working with this repository

This repository contains the original twelve-task Operating Systems assignment structure.
The task objectives, program behavior, sample outputs, and report topics are retained.

## Before publishing

1. Replace Yojith P, 1921260234, and https://github.com/yojith1806-web/CSA-0421-Operating-System/edit/main/CSA0421-1921260234-Assignment-1  in the README, report, and Word document with your own details.
2. Review the environment notes and update them if you run the programs on a different system.
3. Read each task's `run.sh` before execution. Some tasks require Linux tools or elevated permissions.
4. From the repository root, open the required task folder and run its script with `sh run.sh` (or `./run.sh` where executable permissions are available).

## Repository contents

- `Task01`–`Task12`: task source files, scripts, configuration files, and recorded outputs.
- `README.md`: repository overview and task index.
- `REPORT.md` and the Word document: assignment report.
